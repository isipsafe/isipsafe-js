# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-02

### Added

- `Client` with `check`, `isMalicious`, `report`, `bulkReport`, `bulkReportCsv`, `reports`, `allReports`, `checkBlock`, `blocklist`, `blocklistRaw`, `clearAddress` and `categories`.
- `isipsafe` command-line tool.
- ESM and CommonJS builds with TypeScript types, no runtime dependencies, works in Node.js 18+, Deno and Bun.
